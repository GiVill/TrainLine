## Overview

**Sardegna Train Visualization** is a web application that combines real-world open transit data with automated planning techniques to provide two main functionalities:

1. **Interactive map of the Sardinian railway network** — consult official timetables and routes on an interactive map.
2. **Animated simulation of train dispatching** — visualize how trains move through Cagliari station according to a plan generated by a PDDL solver.

The project was developed as part of an **Automated Planning** course project, with the goal of applying formal planning methods (PDDL 2.1) to a real-world railway scheduling problem.

## Features

### 🗺️ Railway Network Map
- Interactive map of the entire Sardinian railway network rendered via **Leaflet**.
- All railway **stations** and **routes** are drawn directly from GTFS dataset files.
- **Search** for a station or train line via the sidebar.
- **Click on a station** to zoom in and view additional details.
- **Click on a route** to trigger a real-time animated train simulation along that track.
- A dedicated button launches a **pre-defined simulation** with three trains heading to Cagliari.

### 🏛️ Cagliari Station Diagram
- A custom **SVG map** of Cagliari station, created from the official technical layout.
- The diagram models the internal track topology including:
  - **Start** — train entry point into the station.
  - **Stop** — passenger boarding/alighting stops.
  - **Exit** — train departure point.
  - **Track** — track segments connecting two nodes.
  - **Switch** — active node allowing a train to change tracks.
  - **Point** — junction connecting two or more track segments.

### 🤖 PDDL-Driven Train Simulation
- Uses the plan generated by a **PDDL 2.1 solver** to animate train dispatching inside Cagliari station.
- Simulates **real-time dispatching** of multiple trains, resolving conflicts (e.g., simultaneous track occupation).
- Displays a **step-by-step log** of all actions performed during the simulation.
- Controls: **Start**, **Reset**, and **Next** step buttons.

## PDDL Planning Model

To formally manage the **entry**, **stop**, and **exit** of trains at Cagliari station, a **PDDL 2.1** model was developed.

### `domain.pddl`
Defines the **types**, **actions**, **preconditions**, and **effects** of the railway domain:
- **Types:** trains, stops, tracks, directions.
- **Actions:** enter station, move between stops, stop, reverse direction, exit station.
- **Constraints:** safety rules (no simultaneous track occupation), collision avoidance.

### `problem.pddl`
Describes a specific planning **instance**:
- **Initial state:** positions of all trains and track availability.
- **Goals:** each train must reach its destination stop, board/alight passengers, and exit the station.

Both a **simplified** and a **complete** version of the domain and problem are provided under `src/assets/pddl/`.

> The solver automatically generates a valid conflict-free plan that coordinates all train movements in an orderly fashion.

## Dataset

The application uses **GTFS (General Transit Feed Specification)** open data for the Sardinian railway network:

| File | Content |
|---|---|
| `shapes.txt` | Geographic coordinates defining the path of each route |
| `stops.txt` | All railway stations and stops |
| `trips.txt` | All individual trips available |
| `stop_times.txt` | Arrival and departure times for each trip |

## Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [Angular CLI](https://angular.dev/tools/cli) v19

```bash
npm install -g @angular/cli
```

### Installation

```bash
# Clone the repository
git clone https://github.com/PeppeLe21/Trenitalia.git
cd SardegnaTrainVisualization-Angular

# Install dependencies
npm install
```

### Running the Application

```bash
ng serve
```

Open your browser and navigate to `http://localhost:4200/`.

### Build for Production

```bash
ng build
```

The compiled output will be placed in the `dist/` directory.
